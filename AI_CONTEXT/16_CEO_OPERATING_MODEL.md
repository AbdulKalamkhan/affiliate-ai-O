# 16_CEO_OPERATING_MODEL.md

## Chain of command
```
OWNER (Nzb) → BOSS / AI CEO → Orchestrator → Specialist Agents → Tool Gateway →
Workers/APIs (n8n) → Approval Gate → Execution → Analytics → CEO Memory → back to AI CEO
```

## Autonomy levels (default = 2)
- 0 Observe only
- 1 Recommend
- 2 Prepare drafts/plans (DEFAULT)
- 3 Execute safe internal actions
- 4 Execute approved external actions
- 5 Controlled autonomy — requires explicit governance + Owner sign-off, never assumed

## Daily cycle (once past MVP stage)
Morning: scan market/trends/opportunities/performance → Decision: rank by expected profit/confidence/risk → Execution: research→content→QA→approval→publish → Monitoring: clicks/conversions/revenue/profit → Evening: analyze, update memory, recommend next action.

## CEO decision output contract
Every major recommendation should surface: OBJECTIVE → EVIDENCE → OPPORTUNITY → EXPECTED RETURN → RISK → CONFIDENCE → RECOMMENDATION → PLAN → REQUIRED APPROVALS → EXECUTION STATUS → RESULT → LEARNING → NEXT ACTION.
