# 15_OPPORTUNITY_ENGINE.md

## Lifecycle
```
DISCOVERED → RESEARCHING → VALIDATING → SCORED → SHORTLISTED →
APPROVED → EXECUTING → LIVE → MEASURING → WINNER / LOSER / WATCH
```

## Critical rule
**Trend ≠ Opportunity. Opportunity ≠ Profit.** Profit potential must be validated with real evidence before a SCORED opportunity is SHORTLISTED — never skip straight from a trend signal to a "go" decision.

## Evidence requirements
Every opportunity record must carry: source, timestamp, freshness, confidence, and a label of FACT / ESTIMATE / INFERENCE / PREDICTION / UNKNOWN for each material claim.

## Phase 00 simplification
For the MVP, this can be a manual/spreadsheet-style list — the full scoring engine (Affiliate-02, Affiliate-03) is a Phase 02/03 concern, not a Phase 00 blocker.
